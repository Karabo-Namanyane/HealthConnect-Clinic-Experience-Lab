# HealthConnect-Clinic-Experience-Lab
This is part of my deliverables as a data analytics intern at AnalystLab Africa. This is going to be an outline of the analysis of HealthConnect Clinic appointment data.

This week`s specific problem for the data analytics track was to understand the HealthConnect_Appointment_Data dataset and identify how it can be used to investigate attendance and no-show patterns. Data review revealed 18 columns and 5001 rows, with the first row containing the column headers.Data Quality checks showed inconsistencies in data formatting and missing values in several columns.
The great no-show rate led me to define 10 business questions and propose 5 KPIs linked to these questions.
The proposed KPIs include but are not limited to % no- shows and % attended.
